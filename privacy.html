개인정보처리방침

최종 수정일: 2026-09-23

1. 수집하는 정보

이 도구는 Google OAuth로 권한을 받은 뒤, YouTube Analytics API(yt-analytics.readonly)에서 채널 소유자 본인의 영상별 성과 지표(조회수, 시청 시간, 평균 조회율, 좋아요·댓글·공유 수, 구독자 증감)를 읽습니다. 이름, 연락처, 시청자 개인을 식별하는 정보는 수집하지 않습니다.

2. 이용 목적

채널 소유자가 자기 영상의 성과를 분석하는 데에만 사용합니다.

3. 저장과 공유

데이터와 인증 토큰은 채널 소유자의 컴퓨터에만 저장되며 외부 서버로 전송하거나 제3자에게 제공·판매하지 않습니다.

4. 권한 철회

언제든 Google 계정의 서드파티 액세스 설정에서 이 도구의 권한을 철회할 수 있습니다. 철회하면 이후 데이터를 더 이상 읽을 수 없습니다.

5. Google API 서비스 사용자 데이터 정책

이 도구가 Google API에서 받은 정보를 사용하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

Privacy Policy (English)

This tool reads the channel owner's own YouTube Analytics metrics (read-only scope yt-analytics.readonly) and stores them, together with the OAuth token, only on the owner's computer. No data is sent to external servers, shared, or sold. It does not collect personal information about viewers. Access can be revoked at any time at Google Account permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
